# OYAGO for Android

**Your city. Your ride. A smarter way to move around Ilesa.**

OYAGO is a ride-hailing app being developed for Ilesa, Osun State, Nigeria.

## Download

The official Android APK will be published here when a release is ready.

No APK has been published yet. Avoid unofficial downloads.

## Installation

1. Open the latest release in the Releases section.
2. Download the APK.
3. Open it on your Android device and follow the installation instructions.

## Official source

The app is maintained in the [OYAGO development repository](https://github.com/Jamie1x-max/Oyago-ilesa-ride).
